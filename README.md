# KhyberApex - Apparel & Leather Manufacturer B2B Portal

A high-performance B2B portal for KhyberApex Manufacturing (Sialkot, Pakistan) showcasing OEM/ODM contract capabilities, material specifications, and interactive RFQ quotation workflows.

## Features
- **Industrial Luxury Theme**: Tailwind CSS dark-mode interface with gold/brass accents.
- **Core Product Lines**: Custom Leather Jackets, Heavyweight Hoodies, Structured Polos, Technical Sportswear.
- **Interactive RFQ**: Dynamic inquiry submission form.
- **Ready for Vercel**: Pre-configured static deployment.

## Deployment to Vercel
1. Import this repository into Vercel.
2. Framework Preset: **Other**
3. Root Directory: `./`
4. Click **Deploy**.
